## 📸 Visage Source Material Pool (`sources/`)

To prevent "clone syndrome" and ensure AI renditions don't look hurriedly generated from a single small source pool, drop your real uncompressed photos into:

```
public/img/personas/sources/
```

- Collect photos from your iPhone, Google Photos, or Amazon Photos across varied lighting, expressions, and angles.
- As your real visage, hair, and style evolve over time, the generator samples from this pool to produce nuanced, authentic, and evolving persona renditions.
- See the full architectural guide in [`docs/PERSONA_PIPELINE.md`](../../../docs/PERSONA_PIPELINE.md).

## 🚀 How to Add New Personas (The Dropzone)

You can drop **N images** at any time into `public/img/personas/dropzone/`:

1. **Drop an image file**:
   Drop `my-persona-name.png` (or `.jpg`, `.jpeg`, `.webp`) into:

   ```
   public/img/personas/dropzone/
   ```

2. _(Optional)_ **Add a sidecar metadata file**:
   If you want custom badges, quotes, and descriptions, add a `.json` with the exact same name (e.g. `my-persona-name.json`):

   ```json
   {
     "name": "The Quantum Architect",
     "hat": "Distributed Systems",
     "role": "Cloud Architect & High-Security Systems",
     "source": "AI Character Rendition",
     "tagline": "Designing architectures that gracefully scale under extreme loads.",
     "realWorldHat": "Enterprise telemetry, Kubernetes microservices, and zero-trust VPCs."
   }
   ```

   _If you omit the JSON, the sync script will automatically derive clean titles, roles, and color themes based on the image filename._

3. **Run the sync command**:
   ```bash
   npm run personas:sync
   ```
   The script moves the image into `public/img/personas/`, updates `data/personas.json`, and cleans up the dropzone.

## ⏰ Automated Recurring Schedule

- A GitHub Actions workflow is located at [`.github/workflows/personas-automation.yml`](../../.github/workflows/personas-automation.yml).
- By default, it runs **bi-weekly** (every 2 weeks on the 1st and 15th) via cron (`0 12 1,15 * *`) and can also be triggered manually (`workflow_dispatch`).
- If new images are present in the dropzone or generated by automated tasks, it automatically synchronizes the carousel roster and commits the update.
